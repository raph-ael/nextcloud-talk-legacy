Paketquellen und Updates

Unter pkg.wolkenfunk.org stellen wir die Linux-Pakete von Wolkenfunk bereit (APT-Paketquelle, AppImage). Wenn Sie dort ein Paket herunterladen oder Ihr System dort nach Updates fragt, verarbeitet der Server dieselben Protokolldaten wie beim Aufruf der Website, zum selben Zweck und mit derselben Speicherdauer. Das gilt auch, wenn die AppImage-Fassung von Wolkenfunk selbst nach Updates sucht (beim Start und danach alle sechs Stunden).
