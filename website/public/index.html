Wolkenfunk

Schnelle, native Clients für Nextcloud Talk.

  • Für Windows herunterladen Windows: bald Windows 10 und 11, 64-Bit
  • Für macOS herunterladen macOS: bald macOS 12 oder neuer, Intel und Apple Silicon
  • Für Linux herunterladen Linux: bald Debian, Ubuntu, AppImage, bald Flathub
  • Für Android herunterladen Android: bald Android 8 oder neuer, APK
  • iOS: bald im App Store iPhone und iPad

Alle Varianten und Installationshinweise

In Entwicklung: frühe Testversionen

Schnell und offline-first

Chats öffnen sofort, auch ohne Netz. Nachrichten gehen raus, sobald die Verbindung wieder steht.

Nativ auf jedem Gerät

Ein gemeinsamer Kern in Rust, darüber echte native Oberflächen für Android, iOS, macOS, Windows und Linux.

Dein Server

Wolkenfunk spricht mit deiner eigenen Nextcloud. Deine Daten bleiben, wo sie hingehören.

Quellcode auf GitHub

Open Source unter AGPL-3.0. Wolkenfunk ist ein unabhängiges Projekt und nicht mit der Nextcloud GmbH verbunden.
