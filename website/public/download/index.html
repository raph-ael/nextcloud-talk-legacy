Wolkenfunk herunterladen

Für Windows, macOS, Linux und Android, bald auch für iOS. Wolkenfunk ist noch in Entwicklung: Was hier „bald“ heißt, folgt in Kürze.

WindowsmacOSLinuxAndroidiOSUpdates

Windows

Für Windows 10 und 11, 64-Bit. Die Installation braucht keine Administratorrechte. Danach aktualisiert sich Wolkenfunk selbst.

Wolkenfunk-Setup.exe herunterladenBald verfügbar

Das Installationsprogramm ist noch nicht signiert. Windows zeigt deshalb beim ersten Start „Der Computer wurde durch Windows geschützt“ und einen unbekannten Herausgeber. Klicke auf „Weitere Informationen“ und dann auf „Trotzdem ausführen“.

Prüfsummen: SHA256SUMS

macOS

Für macOS 12 oder neuer, auf Intel und Apple Silicon. Öffne die .dmg und ziehe Wolkenfunk in den Ordner „Programme“.

Wolkenfunk.dmg herunterladenBald verfügbar

Wolkenfunk ist noch nicht von Apple beglaubigt. Beim ersten Start meldet macOS deshalb „„Wolkenfunk“ nicht geöffnet“. Klicke auf „Fertig“, nicht auf den blauen Knopf „In den Papierkorb legen“, der die App löscht. Öffne dann Systemeinstellungen › Datenschutz & Sicherheit, scrolle zum Abschnitt „Sicherheit“ und klicke bei „„Wolkenfunk“ wurde blockiert, um deinen Mac zu schützen.“ auf „Dennoch öffnen“. Bestätige mit deinem Passwort oder Touch ID. Das ist nur beim ersten Mal nötig.

Updates gibt es unter macOS vorerst nicht automatisch: Lade für eine neue Version die .dmg erneut und ersetze die App im Ordner „Programme“.

Prüfsummen: SHA256SUMS

Linux

Debian und Ubuntu

Lade das Paket herunter und installiere es per Doppelklick oder im Terminal. Dabei richtet es die Wolkenfunk-Paketquelle ein, Updates kommen danach mit den normalen Systemupdates.

.deb herunterladenBald verfügbar

sudo apt install ./wolkenfunk_amd64.deb

Oder nur die Paketquelle einrichten und dann installieren:

sudo curl -fsSLo /etc/apt/sources.list.d/wolkenfunk.sources \
  https://pkg.wolkenfunk.org/apt/wolkenfunk.sources
sudo apt update && sudo apt install wolkenfunk

Ab Debian 12 und Ubuntu 22.04, 64-Bit (x86_64). Die Pakete sind signiert mit dem Schlüssel F980 BE28 D9EA 63A0 7A86 6E13 3641 FF50 244C 4126 (öffentlicher Schlüssel).

Prüfsummen: SHA256SUMS

AppImage

Eine Datei für alle Distributionen, ohne Installation und ohne Administratorrechte. Das AppImage aktualisiert sich selbst.

AppImage herunterladenBald verfügbar

chmod +x Wolkenfunk-x86_64.AppImage
./Wolkenfunk-x86_64.AppImage

Prüfsummen: SHA256SUMS

Flathub

Wolkenfunk kommt auf Flathub und ist dann direkt in GNOME Software, KDE Discover und anderen Software-Centern zu finden. Updates laufen dort automatisch.

Bald auf Flathub

Android

Für Android 8 oder neuer. Die APK läuft auf allen gängigen Geräten.

wolkenfunk.apk herunterladenBald verfügbar

Beim Öffnen der APK fragt Android, ob dein Browser oder Dateimanager Apps installieren darf: Erlaube das unter „Aus dieser Quelle zulassen“. Warnt Google Play Protect vor einer unbekannten App, wähle „Trotzdem installieren“.

Die APK aktualisiert sich nicht selbst. Für eine neue Version lade sie erneut und installiere sie über die alte; Konto und Chats bleiben erhalten.

Kleinere Varianten nur für einen Prozessortyp (arm64-v8a für aktuelle Geräte, armeabi-v7a für ältere) liegen im Download-Ordner.

Die APK ist signiert mit dem Zertifikat (SHA-256) FC:2D:D9:F9:C5:92:4D:A3:73:40:8E:DD:31:00:12:65:4F:2D:D0:47:F6:C6:77:B8:A8:F0:E8:A6:09:BC:42:99. Prüfen kannst du das am Rechner mit apksigner verify --print-certs wolkenfunk.apk oder auf dem Handy mit der App AppVerifier.

Prüfsummen: SHA256SUMS
